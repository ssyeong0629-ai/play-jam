# Changelog

## 0.1.0 — 2026-11-06

- Rebuilt the original PLAY JAM HTML into a local-first static editor.
- Added 36 supplied SVGs, compact typography and six color rows with shape-family columns.
- Unified random/direct placement; selection, handles, keyboard controls and effect-first deletion.
- Added soft snap, optional beat snap, BPM, seeking, loop toggle and automatic 7/8-staff pagination.
- Added responsive Library, native synthesis, PNG/PDF/project/wallpaper/link export and experimental native recording.
- Removed the separate Toy mode; placement feedback remains in the editor.
- DOM checks passed for placement interval, effects, undo, pagination, SVG generation and keyboard transforms.
