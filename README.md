## 편집
- Figma 개선안 03의 실제 팔레트 순서: 30개 제작 SVG + 6색 동그라미, 6행 × 6열.
- 원형만 18px, 제작 아이콘 26px. 포스터 좌표계 기준이며 확대 비율을 따릅니다.
- 클릭으로 하나 배치, 드래그로 연속 배치. 선택한 아이콘 종류는 유지됩니다.
- 13개 세로 위치 스냅, 가로는 자유 배치. 단 사이 공백은 비웁니다.
- 아이콘 클릭 선택, Shift 클릭 다중 선택/해제. 선택한 아이콘을 드래그하면 함께 이동합니다.
- 작업 헤더의 Delete 버튼으로 삭제 모드를 켠 뒤 아이콘을 클릭하면 삭제합니다. 다시 누르거나 Esc로 해제합니다. 아이콘을 새로 고르면 배치 모드로 돌아갑니다.
- 개별 × 버튼은 제거했습니다. Delete/Backspace로 선택 삭제하는 키보드 조작은 유지합니다.
- Cmd/Ctrl+Z 실행 취소, Cmd/Ctrl+Shift+Z 다시 실행.
- 크기/회전 조절, 랜덤, 단 추가/삭제, 페이지 넘김, 개별 × 삭제 버튼 없음. 작업 헤더의 Delete 모드 버튼은 유지합니다.
- 7단 첫 페이지, 이후 8단. 마지막 단 끝에 놓으면 다음 페이지를 준비합니다. 빈 페이지는 삭제 후 정리됩니다.
- 장식 밀도는 배치와 소리를 변경하지 않습니다. 연결은 같은 단의 가까운 기호에만 생성됩니다.

## 사이드바 / 시작 / 저장
- 사이드바 접기 시 캔버스가 넓어지고 오른쪽 아래 원형 팔레트가 표시됩니다.
- 원형 팔레트: 컬러 선택 → 해당 컬러의 기호 선택. 선택 후 자동으로 접힙니다.
- 시작 화면, 건너뛰기, 실제 도구 위치를 강조하는 4단계 사용법, 다시 보기 포함.
- 자동 저장은 playjam.project.v3 키를 사용합니다. 공유받은 작품은 playjam.shared.v3에 별도로 저장하여 내 작업을 덮어쓰지 않습니다. 이전 v2 저장도 유지합니다.
- 드래그 중 캔버스 가장자리에서 자동 스크롤합니다. 재생선은 단 사이 여백을 지나서도 이동할 수 있습니다.
- 재생선에 키보드 초점을 놓고 좌우 방향키로 반 박자씩 이동할 수 있습니다.
- PNG에 정지 상태의 연결선과 장식이 포함됩니다. 모든 페이지 체크 시 페이지별 다운로드. 비어 있는 임시 다음 페이지는 내보내지 않습니다. 여러 파일 저장을 브라우저가 차단하면 페이지별로 저장하세요.
- 공유 링크는 GitHub Pages에서 생성합니다. 수신자는 같은 배치/장식/속도로 PLAY를 누를 수 있습니다.

## 사운드
12개 실제 녹음 파일을 기반으로 36개의 고정 샘플·패턴 조합을 연결했습니다.
드럼, 샘플 기반 신디, 베이스, 어쿠스틱, 클린 일렉, 디스토션 일렉의 6개 군입니다.
신디는 녹음된 Unitra 건반 소스를 필터·엔벌로프로 가공하며, 디스토션은 실제 일렉 기타 녹음에 드라이브를 적용합니다. 오실레이터 대체음은 없습니다.
BPM은 패턴 간격을 바꾸며, 최종 샘플의 재생 길이와 게이트 종료를 계산해 자동 정지합니다. 위치 이동 시 진행 중이던 샘플/패턴을 해당 지점부터 재개합니다.
로컬 실행을 위해 bank.js에 WAV가 내장되어 있어 외부 음원 요청이 필요 없습니다.

## 명세와 아직 다른 부분 — 숨기지 않음
완전한 원음 주법 36종 세트는 아닙니다. 베이스 피크/팝핑과 클린 일렉 하모닉스의 원음은 미확보 상태입니다. 현재 2-1은 스타카토, 2-3과 4-4는 옥타브로 명시되어 있으며 해당 주법으로 표기하지 않습니다.
슬라이드/벤딩은 녹음 샘플의 피치 변화, 스트로크/아르페지오는 샘플 시퀀싱, 팜뮤트는 짧은 기타 녹음의 게이트/필터/드라이브로 구현했습니다. 이들을 독립된 실제 주법 녹음으로 주장하지 않습니다.
아이콘별 최종 주법 대응과 음질 청취 평가는 최종 확인이 필요합니다. 자세한 대응은 assets/audio/voice-map.json을 확인하세요. 파일 번호로 연주법을 결정한 것이 아닙니다.
모바일 기본 반응형을 제공하지만 터치 전용 레이아웃·다중 터치 검증은 남아 있습니다.
