## 실행 / GitHub 교체
압축을 풀고 index.html, css, js, assets를 기존 index.html이 있는 위치에 덮어쓰세요. ZIP 자체를 업로드하지 마세요. index.html을 직접 열어도 실행됩니다. 설치와 빌드는 없습니다. Clarity zcrpqz8ze9는 head에 유지했습니다.

## 편집 방법
- 제작 SVG 30개 + 원형 6개, 6색 × 6개 팔레트입니다. 원형 18px, 제작 아이콘 26px입니다.
- 한 번 선택한 아이콘을 클릭/드래그로 계속 배치합니다. 빠른 드래그 구간도 보간하며, 최소 간격과 오선지 13개 위치 스냅을 적용합니다.
- 기존 아이콘 클릭은 선택이며 삭제되지 않습니다. Shift 클릭으로 다중 선택, 선택한 아이콘을 드래그하면 함께 이동합니다. 다른 아이콘과 겹치는 이동은 제한합니다.
- 작업 헤더 Delete를 켜고 아이콘을 클릭하면 삭제합니다. 다시 Delete/Esc를 누르면 종료합니다. 선택 아이콘은 키보드 Delete/Backspace로도 삭제할 수 있습니다.
- 전체 초기화는 Delete 오른쪽입니다. 확인 후 모든 페이지의 아이콘/장식을 지웁니다. 제목·작가·BPM·테마·밀도는 유지하고 Undo로 복구할 수 있습니다.
- Cmd/Ctrl+Z 실행 취소, Cmd/Ctrl+Shift+Z 다시 실행.
- 첫 페이지 7단, 이후 페이지 8단. 마지막 단 오른쪽 끝에 배치하면 다음 페이지를 준비하며 세로로 이어집니다. 현재 한 작품 최대 63단/5,000아이콘 제한이 있습니다.
- 단 사이 공백에는 배치하지 않습니다. 가장자리 드래그 시 자동 스크롤합니다.
- 크기/회전 조절, 랜덤, 수동 단/페이지 추가·이동, 개별 × 삭제 버튼은 없습니다.

## 화면 / 저장
- 작업 헤더 맨 왼쪽 ☰로 사이드바를 접습니다. 접으면 우측 하단 원형 팔레트에서 컬러 → 아이콘 순으로 선택합니다.
- 100%는 현재 캔버스 너비 기준입니다. 확대/축소 및 화면 맞춤을 제공합니다.
- START, 건너뛰기, 편집 도구 위 4단계 안내, ? 다시 보기를 제공합니다.
- 장식 밀도는 아이콘 위치·소리를 바꾸지 않습니다. 같은 단의 가까운 아이콘끼리 연결하며 정지 상태에도 장식이 남습니다.
- 공유/내보내기 아이콘 하나에서 PNG와 링크 복사를 제공합니다. PNG에는 연결선·장식이 포함됩니다. 모든 페이지 체크 시 페이지별 저장합니다. 비어 있는 임시 다음 페이지는 제외합니다.
- 링크 공유는 GitHub Pages에서 사용하세요. 로컬 파일에서는 링크 복사를 제한합니다. 작품이 크면 링크가 길어져 일부 메신저에서 제한될 수 있습니다.
- 내 작품과 공유받은 작품은 별도로 자동 저장합니다. 공유 작품은 링크별로 저장하며 수정 후 새로고침해도 복원됩니다.

## 사운드
56개 실제 녹음으로 36개 고정 주법/패턴을 재생합니다. 이전 12개 중 7개를 유지하고 49개를 추가 연결했습니다. 음높이에 가까운 녹음을 선택하는 멀티샘플 방식입니다. 같은 위치의 같은 아이콘은 같은 음색/패턴을 재생합니다.
- 핑거/피크 베이스의 다중 음역
- 두 대의 일렉 기타 다중 음역
- 어쿠스틱 약/강 피킹 다중 음역
- 실제 Unitra 아날로그 건반 4개 음색을 신디 음색으로 가공
- 드럼 단타/패턴, 오픈/페달 하이햇 추가
- 실제 일렉 팜뮤트와 어쿠스틱 뮤트 코드

오실레이터 효과음 대체는 없습니다. WAV가 bank.js에 내장되어 오프라인 재생이 가능합니다. BPM에 따라 패턴 간격이 달라집니다. 마지막 소리 끝에서 자동 정지하며, 드래그/방향키로 재생 위치를 바꿀 수 있습니다. 디스토션 잔류 신호와 벤딩 중간 재개 위치를 수정했습니다.

## 남은 항목
베이스 팝핑과 클린 일렉 하모닉스의 적합한 원음은 아직 확정하지 못했습니다. 해당 슬롯 2-3, 4-4는 옥타브로 명확히 표기했습니다. 하모닉스 후보는 확보했지만 단일음 분리/조율이 불안정하여 최종 은행에서 제외했습니다.
슬라이드/벤딩은 샘플 피치 변화, 스트로크/아르페지오는 샘플 시퀀싱입니다. 독립된 원음 주법 36종 세트는 아닙니다. 음질의 주관적 청취 평가는 남아 있습니다. 모바일은 기본 대응이며 터치 전용 완성 검증은 남아 있습니다. PDF/영상은 이번 필수 범위 밖입니다.
